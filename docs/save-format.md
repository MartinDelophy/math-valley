# 存档与关卡更新

游戏在同一设备、同一浏览器来源或同一个桌面应用配置中使用 IndexedDB 自动存档。升级游戏和追加关卡不清空数据库。旅程存档入口在开场右下角，也可从设置中导入、导出备份。

- 以永久关卡 ID 关联进度，不按数组下标关联；追加第三章时使用新的 ID，例如 `3-01`，不要重新编号已有关卡。
- 保留当前关卡、操作状态、视角、已完成关卡、教学记录、偏好和往昔旅程。新关卡单独标记，完成后移出新增列表。
- 暂时不在目录中的合法关卡记录也保留，避免较旧的游戏版本抹掉较新章节的存档。
- 如果关卡规则变化，原有规则指纹验证可能只使该关的操作状态失效；其他关卡与已完成记录继续保留。
- 导入会先核对格式和版本，把传入旅程加入备份，再使用原有原子旅程切换恢复。当前旅程先自动归档；旧标签页不能覆盖新旅程。

## 便携备份

导出为本地 JSON 文件，可以在另一浏览器或桌面版导入。导入前显示完成数量和往昔旅程数量，再由玩家点击恢复。文件不上传到服务器。存档导出格式版本与游戏内容版本分开：新增关卡不要求改变文件格式。遇到不支持的格式版本时拒绝导入，保留当前旅程。

外层结构：

```json
{
  "format": "math-valley-save",
  "version": 1,
  "contentVersion": 1,
  "exportedAt": "ISO 8601 timestamp",
  "payload": {
    "schemaVersion": 1,
    "profile": {},
    "levels": [],
    "archives": []
  }
}
```

自动存档属于浏览器/应用本机数据；清除这些数据会影响自动存档。导出的 JSON 可作为独立备份。此版本没有账号云同步。

验证包括：关卡目录扩充后重开、暂时下线的关卡保留、跨数据库导出/导入、当前旅程归档、损坏和未来格式拒绝、旧标签页冲突，以及实际应用中的下载、文件预览、恢复与再次启动。
